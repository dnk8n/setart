# Notes for AI agents

Read `docs/CONTRIBUTING.md` before changing anything; it defines where code goes and the
determinism rules. Commands: `uv sync`, `uv run pytest -q`, `uv run ruff check .`,
`uv run ruff format .`, `uv run setart render <album> --seed N --scale 0.25`.

Never commit rendered output (`out/`) or any static image, font or texture asset.
